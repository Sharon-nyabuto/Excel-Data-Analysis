# Excel Data Analysis Projects

A collection of data analysis projects completed using Microsoft Excel. The projects cover data cleaning, analysis, reporting, and dashboard development using different datasets and business contexts.

## Projects

### Coffee Shop Sales Analysis

Analysis of coffee shop sales data to explore sales performance, product trends, and customer purchasing patterns.

### Jumia Sales Analysis

Analysis of e-commerce sales data to examine sales performance, products, and other relevant patterns in the dataset.

### Food Basket Project

Analysis of household and food basket data to explore patterns across households and locations.

Each project folder contains the relevant dataset, analysis files, dashboard(s), and supporting documentation where applicable.

## Tools

* Microsoft Excel
* PivotTables and PivotCharts
* Excel formulas
* Data cleaning and analysis
* Dashboard development
